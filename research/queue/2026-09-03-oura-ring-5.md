# Oura Ring 5 — new flagship hardware, existing cloud API

**Severity:** FYI
**Category:** devices
**Date flagged:** 2026-09-03

## Summary

Oura's official announcement (2026-05-28, via Business Wire) introduces Oura Ring 5 — its
smallest-ever ring, with next-gen sensing and week-long battery life. Oura's third-party
integrations continue to run through its existing cloud API.

# Garmin Connect Developer Program applications remain frozen ~5 months in, no reopening date — deprioritize signal for the placeholder Garmin integration

**Date:** 2026-09-18
**Severity:** FYI
**Category:** devices
**Source:** https://forums.garmin.com/developer/connect-iq/f/discussion/434798/cannot-access-developer-program-application-form-under-construction

## Summary

Garmin has not reopened new Garmin Connect Developer Program applications since pausing them in spring 2026 (following a Strava API-terms lawsuit); the application form is still removed as of 2026-09-14 with no announced ETA. Garmin separately acquired TrainingPeaks/TrainHeroic on 2026-07-22, possibly tied to an internal redesign of the developer program. Existing approved integrations are unaffected; only new onboarding is blocked.

## Why flagged

Roadmap intelligence only — Garmin is a placeholder with no live client id, so this is not a current integration risk. It is a negative signal against prioritising the Garmin build-out right now, since there is currently no path to even request access.

## Next question / action

Deprioritize the Garmin placeholder on the roadmap until the developer program reopens.
